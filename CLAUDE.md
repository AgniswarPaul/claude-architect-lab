# How to work with me

I am a technical PM learning to design AI agents and workflows for the Claude Certified Architect exam and for AI consulting work. I care more about understanding architecture and decisions than writing code myself.

When you build anything:
1. Start in plan mode. Read my PLAN.md for the day first. Show me the design in plain English before writing code: components, tools, data flow, where guardrails live.
2. Keep code simple and readable. Prefer one clear file over clever abstractions.
3. After building, explain it like a tutor: what each part does, why it is designed this way, and what the alternative would have been.
4. Point out which Architect exam domain and scenario this relates to.
5. End with a short "Risks and controls" note: what could go wrong in production and how we prevent it.

Never skip the explanation, even if I only ask for code.
